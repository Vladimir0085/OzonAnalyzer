# OZ Price Analyzer

Локальное приложение для анализа отчетов Ozon без Excel и VBA. Оно переносит расчет из отчета v11, хранит историю в SQLite, показывает исходные книги прямо в приложении и рассчитывает доходность при плановой цене.

## Что уже работает

- пакетный импорт: каждый выбранный отчет по начислениям создает отдельный расчет, а `RealizationReportCIS` автоматически прикрепляется к совпадающему месяцу и году;
- сверка календарного месяца и года отчетов по начислениям и выкупам перед расчетом;
- проверка формата, обязательных заголовков и арифметики `RealizationReportCIS`;
- распределение каждой строки начислений по фактическому наличию артикула;
- расчет количества продаж только по строкам группы «Продажи» с отдельным вычитанием группы «Возвраты», без повторного уменьшения из-за отрицательных баллов и программ партнеров;
- отдельная «Разбивка» для доходов и расходов без артикула;
- запрос о создании неизвестного товара с вводом полной себестоимости и трудозатрат;
- пустой справочник при первой установке с последующей загрузкой проверяемого XLSX;
- категории товаров в справочнике, обзоре и сценарии цены;
- безопасная полная очистка текущего справочника с предупреждением; сохраненные отчеты при этом не удаляются;
- начальная группировка справочника `БРГС` → `ГС` → `Бант` и сохраняемое ручное перемещение вверх/вниз;
- основной редактор себестоимости внутри приложения: поиск, фильтр, добавление и изменение нескольких товаров;
- массовый экспорт и импорт себестоимости через проверяемый XLSX-шаблон;
- предварительное сравнение старых и новых значений и журнал изменений себестоимости;
- переносимая резервная копия истории, настроек, себестоимости и исходных отчетов;
- история расчетов, исходных файлов и контрольных предупреждений в SQLite;
- редактируемые наименования отчетов и удаление ненужных расчетов из истории;
- безопасное обновление отчета за уже существующий период без двойного учета сумм;
- непрерывная нумерация отчетов по их текущей позиции в отсортированной истории;
- контроль качества выделенного отчета без необходимости открывать весь расчет;
- хронологический порядок истории по отчетному периоду: от меньшего года и месяца к большему;
- фильтр истории по одному, нескольким или всем годам;
- сравнение двух сохраненных периодов по товарам, выручке, продажам и чистой прибыли;
- график динамики выручки, чистой прибыли, продаж, нераспределенных сумм и процентных показателей от выручки по истории;
- копия каждого исходного файла в локальном хранилище приложения;
- просмотр сохраненных исходников и любой выбранной книги XLSX без запуска Excel;
- отдельная панель над предпросмотром с открытием произвольного XLSX и полной очисткой блока;
- единый активный набор отчетов для вкладок «Обзор», «Исходные файлы», «Разбивка» и «Сценарий цены»: действует верхний список либо последний выбор через кнопку «Выбрать отчеты…»;
- справочник начислений с отдельным статусом текущего запуска и накопленной истории;
- сценарий доходности для индивидуальной цены или массового изменения в процентах;
- применение процента изменения цены как ко всем товарам, так и только к выделенной строке сценария;
- фильтр по категории и поиск по артикулу в обзоре и сценарии цены;
- сортировка обзора и сценария по доходности, чистой прибыли, выручке и количеству продаж в обоих направлениях;
- отдельные итоги выбранной категории в «Обзоре»: выручка, чистая прибыль, доходность, продажи, себестоимость проданного и финансовый результат Ozon;
- доли средней комиссии, полной логистики, баллов и чистой прибыли от выручки в «Обзоре», «Динамике» и экспортируемом XLSX;
- в карточках «Обзора» сумма комиссии, полной логистики и баллов в рублях показана рядом с соответствующим процентом от выручки;
- в карточке итоговой прибыли после налога показана доходность всего отчета: итог с нераспределенными, деленный на себестоимость проданного;
- компактная компоновка «Обзора» и автоматическое деление рабочей области поровну между показателями и товарной таблицей;
- доходность в общем графике «Динамики» и фильтр периода по текущему году или выбранным годам истории;
- встроенная вкладка «Справка» с перечнем обязательных и дополнительных отчетов Ozon, путями их скачивания и формулами показателей «Обзора»;
- отдельные сохраняемые настройки видимости и порядка столбцов таблиц «Обзор» и «Сценарий цены»;
- экспорт итоговой книги `КонсОтчет` + `Разбивка` в XLSX;
- единственный экземпляр приложения: повторный запуск восстанавливает уже открытое окно вместо создания второго;
- системная, темная и светлая темы в стиле Windows 11;
- выбор папки хранилища с проверяемым переносом накопленных данных из настроек.

Отдельный `CompensationReport` и снятый Ozon «Отчет по товарам» намеренно не используются. Компенсации берутся из отчета по начислениям: с артикулом относятся к товару, без артикула — в «Разбивку». Любой положительный нераспределенный доход Ozon включается в налогооблагаемую базу, но не увеличивает товарную выручку и товарную чистую прибыль; налог с него вычитается из итоговой прибыли отчета. Акты Ozon PDF о премиях и компенсациях, отсутствующих в отчете по начислениям, можно выбрать вместе с XLSX за тот же месяц — приложение добавит их как отдельный нераспределенный доход.

При первой установке справочник себестоимости пуст. Во вкладке «Настройки» нажмите «Загрузить XLSX» и выберите `Справочник_себестоимости_OZON.xlsx`. Поддерживается новый столбец «Категория»; старый шаблон без него также читается, а категория остается пустой. После первоначальной загрузки товары можно редактировать непосредственно в приложении. Материал рассчитывается автоматически как полная себестоимость минус трудозатраты.

Категория считается текущей классификацией товара: при ее изменении она обновляется в строках сохраненной истории, но себестоимость и все числовые показатели прошлых отчетов остаются неизменными. В «Обзоре» и «Сценарии цены» доступны категория «Без категории», поиск по части артикула и сортировка по ключевым показателям. Кнопка «Очистить справочник» удаляет только текущий каталог товаров после подтверждения и не удаляет сформированные отчеты.

В «Обзоре» общие итоги отчета и итоги выбранной категории показываются раздельно. Категорийные показатели рассчитываются по всем товарам выбранной категории независимо от поиска по артикулу и порядка сортировки. Нераспределенные доходы и расходы в итоги категории не включаются. Доходность категории равна суммарной чистой прибыли категории, деленной на суммарную себестоимость проданных товаров этой категории.

Процентные показатели используют выручку с баллами как знаменатель. Средняя комиссия считается как комиссия Ozon со знаком расхода. Полная логистика включает «Доставку до ПВЗ», «Логистику», «Обратную логистику» и «Возвраты/отмены». Итоговая доля чистой прибыли учитывает нераспределенные доходы и расходы всего отчета; показатели отдельных товаров их не включают, поскольку общая сумма не распределяется между артикулами. Кнопка «Настроить столбцы…» на вкладках «Обзор» и «Сценарий цены» позволяет независимо скрывать столбцы и менять их порядок; обе настройки сохраняются в базе приложения.

Новые значения применяются только к будущим расчетам: сохраненные периоды содержат собственный снимок себестоимости и не пересчитываются.

## Запуск в Windows

### Готовая версия без Python и Excel

В GitHub откройте `Actions` → `Windows application`, выберите успешный запуск и скачайте артефакт `OZPriceAnalyzer-Windows-x64-v<версия>`. Распакуйте ZIP в обычную папку и запустите `OZPriceAnalyzer.exe`. При повторном запуске новое окно не создается: существующее окно восстанавливается и выводится на передний план. История и справочники хранятся отдельно от программы, поэтому обновление папки приложения их не удаляет.

Пока в репозитории не настроен сертификат издателя, Windows может показать стандартное предупреждение для неподписанного приложения. Это не влияет на расчеты; настройка подписи описана в [инструкции по выпуску](docs/RELEASING.md).

### Запуск из исходного кода

1. Установите Python 3.11 или новее с сайта Python и включите пункт `Add Python to PATH`.
2. Запустите `run_windows.bat`.
3. При первом запуске будет создано окружение и установлена единственная внешняя зависимость — `openpyxl`.

Чтобы самостоятельно получить автономную Windows-сборку, запустите `build_windows.bat`. Готовая программа появится в `dist\OZPriceAnalyzer`, а переносимый ZIP — в `artifacts`.

## Обычный запуск разработчика

```bash
python -m venv .venv
.venv/Scripts/activate
pip install -r requirements.txt
python main.py
```

Для Linux или macOS команда активации окружения отличается: `source .venv/bin/activate`.

## Правила расчета

| Ситуация | Действие |
|---|---|
| У строки начисления есть артикул | Сумма относится к товару и к подходящему аналитическому столбцу |
| У строки начисления нет артикула | Сумма входит в «Нераспределенные доходы / расходы» и лист «Разбивка» |
| Выручка, баллы или программа партнеров относятся к группе «Продажи» | Строки объединяются по ID начисления, артикулу и цене продавца для расчета проданного количества |
| Баллы или программа партнеров относятся к группе «Возвраты» | Суммы учитываются в финансовом результате, но повторно не уменьшают количество продаж |
| Строка имеет тип «Возврат выручки» | Количество вычитается из продаж один раз, в том числе для возврата продажи прошлого периода |
| Тип начисления новый, артикул есть | Сумма относится к «Прочим начислениям по товару» |
| Тип начисления новый, артикула нет | Сумма входит в «Разбивку» под исходным названием типа |
| Артикул не заведен | Приложение предлагает создать товар и ввести себестоимость либо пропустить строки |
| В истории уже есть отчет за тот же период | Можно заменить его новым либо прервать импорт; двойное сложение сумм запрещено |
| Файл повторно выбран в одном импорте или использован в другом периоде | Импорт прерывается, чтобы не удваивать суммы |
| `RealizationReportCIS` поврежден | Импорт останавливается с указанием проблемной строки |
| Выбрано несколько отчетов по начислениям за разные месяцы | Для каждого файла создается отдельный расчет; общий многомесячный отчет не формируется |
| При пакетном импорте месяц `RealizationReportCIS` совпадает ровно с одним отчетом начислений | Файл выкупов автоматически включается только в расчет этого месяца |
| При пакетном импорте для `RealizationReportCIS` нет подходящего месяца или выбор неоднозначен | Импорт останавливается, чтобы не отнести выручку не к тому периоду |
| При одиночном импорте месяц или год `RealizationReportCIS` не совпадает с начислениями | Можно продолжить с предупреждением либо отменить импорт; принятое расхождение сохраняется в контроле качества |
| При одиночном импорте период `RealizationReportCIS` не найден или охватывает несколько месяцев | Приложение также требует подтверждения перед продолжением |
| Отчета о выкупленных товарах нет | Приложение предупреждает, но разрешает продолжить |

При обновлении периода новый расчет сохраняется и только затем заменяет старый в одной транзакции. Пользовательское наименование отчета сохраняется. Если новые файлы не пройдут проверку или расчет, прежний отчет останется без изменений.

## Где хранятся данные

По умолчанию в Windows используется `%LOCALAPPDATA%\OZPriceAnalyzer`:

- `ozpriceanalyzer.sqlite3` — история, настройки, товары и сценарные цены;
- `source_files` — неизмененные копии исходных XLSX;
- `exports` — предложенная папка для итоговых отчетов;
- `backups` — резервные и автоматические страховочные копии перед восстановлением.

Во вкладке «Настройки» можно создать один файл `.ozbackup` и перенести его на другой компьютер. Перед восстановлением приложение проверяет структуру архива, контрольные суммы всех файлов и целостность SQLite. Текущие данные заменяются только после подтверждения пользователя, причем сначала автоматически сохраняется отдельная страховочная копия. Пути к исходным отчетам переписываются под новое расположение приложения.

Путь виден во вкладке «Настройки». Для разработки его можно переопределить переменной `OZON_APP_DATA`.

Кнопка `Изменить…` рядом с путем позволяет выбрать пустую папку и перенести туда базу, себестоимость, историю, исходные файлы, экспорты и резервные копии. Новая папка используется сразу и при следующих запусках. Старая папка автоматически не удаляется и остается страховочной копией.

## Проверка

```bash
python -m unittest discover -s tests -v
```

Для регрессионной проверки на реальных выгрузках задайте `OZON_REPORTS_DIR` — путь к папке с исходными файлами. Без него тест реальных отчетов корректно пропускается.

Подробные результаты анализа исходных файлов и проектные решения находятся в [docs/PRODUCT_DESIGN.md](docs/PRODUCT_DESIGN.md), а порядок Windows-сборки — в [docs/RELEASING.md](docs/RELEASING.md).
