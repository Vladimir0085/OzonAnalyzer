OZ PRICE ANALYZER ДЛЯ WINDOWS

Версия 0.5.25: верхний список и кнопка «Выбрать отчеты…» задают один активный
набор для вкладок «Обзор», «Исходные файлы», «Разбивка» и «Сценарий цены».
Блоки «Обзора» стали компактнее, а таблица занимает половину рабочей области.

1. Распакуйте ZIP-архив полностью в отдельную папку.
2. Запустите OZPriceAnalyzer.exe.
3. Python и Microsoft Excel для работы приложения не требуются.
4. При первом запуске откройте «Настройки» и загрузите XLSX-справочник
   себестоимости: встроенный справочник изначально пуст.

Данные пользователя хранятся отдельно от программы:
%LOCALAPPDATA%\OZPriceAnalyzer

Перед переносом на другой компьютер создайте файл резервной копии во вкладке
«Настройки» и восстановите его на новом компьютере.

Если Windows сообщает, что издатель не подтвержден, проверьте, что архив получен
из официального репозитория OZPriceAnalyzer. До подключения сертификата некоторые
тестовые сборки могут не иметь цифровой подписи.
