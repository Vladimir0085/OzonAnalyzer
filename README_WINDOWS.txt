OZ PRICE ANALYZER ДЛЯ WINDOWS

Версия 0.5.31: улучшения интерфейса, расчёты не изменены. «О программе» — в
одной строке с «Экспорт в Excel»; в верхнем списке отчёт показан кратко
(«№4 · 01.08–31.08.2026»), полное название — в подсказке. На карточках «Обзора»
при наведении видна формула из «Справки»; карточка «Баллы» переименована в
«Баллы Ozon (доход)». Вместо 0,00% доходности показывается «Нет продаж» или
«Нет себестоимости». Развёрнутые таблицы больше не закрывают заголовки
столбцов, строки «Сценария цены» переносятся в узком окне, а над справочником
себестоимости видно предупреждение о строках без полной себестоимости.

1. Распакуйте ZIP-архив полностью в отдельную папку.
2. Запустите OZPriceAnalyzer.exe.
3. Python и Microsoft Excel для работы приложения не требуются.
4. При первом запуске откройте вкладку «Справочник себестоимости» и загрузите
   XLSX-справочник: встроенный справочник изначально пуст.

Данные пользователя хранятся отдельно от программы:
%LOCALAPPDATA%\OZPriceAnalyzer

Перед переносом на другой компьютер создайте файл резервной копии во вкладке
«Настройки» и восстановите его на новом компьютере.

Если Windows сообщает, что издатель не подтвержден, проверьте, что архив получен
из официального репозитория OZPriceAnalyzer. До подключения сертификата некоторые
тестовые сборки могут не иметь цифровой подписи.
