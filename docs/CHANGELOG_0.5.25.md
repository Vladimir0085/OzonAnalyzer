# OZ Price Analyzer 0.5.25

- Верхний список отчётов и окно «Выбрать отчёты…» теперь управляют единым активным набором: действует способ выбора, использованный последним.
- Один и тот же набор отчётов показывают вкладки «Обзор», «Исходные файлы», «Разбивка» и «Сценарий цены».
- Для нескольких отчётов сценарий цены показывает сводные показатели. Изменение и сохранение плановых цен доступно только при выборе одного отчёта, чтобы цена не была записана в неверный период.
- Карточки, фильтры и кнопки вкладки «Обзор» получили компактные отступы и типографику.
- Карточки комиссии, логистики, баллов и чистой прибыли объединяют подпись и значение в одной строке.
- Товарная таблица автоматически получает половину рабочей области вкладки «Обзор» при любом размере окна и разрешении монитора.
- Встроенная справка дополнена описанием единого выбора отчётов.
