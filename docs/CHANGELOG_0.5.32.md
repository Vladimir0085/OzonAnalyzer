# OZ Price Analyzer 0.5.32

Удобное редактирование абсолютной плановой цены отдельной позиции. Формулы
сценария, импорт отчётов, база данных и экспорт не изменены.

## «Сценарий цены»

- Двойной щелчок по ячейке «Плановая цена» открывает редактор непосредственно
  поверх выбранной ячейки.
- Клавиша F2 открывает такой же редактор для выделенной строки.
- Enter сохраняет абсолютную цену только выбранной позиции и сразу пересчитывает
  её плановую доходность, прибыль, налог, комиссию и общие карточки сценария.
- Esc закрывает редактор без сохранения.
- Если столбец «Плановая цена» скрыт в настройках, F2 переводит фокус в обычное
  поле цены над таблицей.
- Поле «Плановая цена выбранной позиции» над таблицей сохранено; Enter в нём
  теперь работает так же, как кнопка «Сохранить цену».
- Изменение цены в процентах для выбранной позиции или всех товаров сохранено.

## Проверка

- Добавлены интерфейсные тесты сохранения абсолютной цены, немедленного
  пересчёта доходности и отмены редактирования.
- Полный набор автоматических тестов должен выполняться перед Windows-сборкой.
