# OZ Price Analyzer 0.5.29

- Защита от двойного учёта PDF-актов Ozon о премиях и компенсациях. После сопоставления акта с отчётом по начислениям за месяц программа ищет в этом отчёте положительные строки без артикула на ту же сумму (±0,01 ₽).
- При совпадении появляется вопрос «Возможен двойной учёт: акт № … от … на … ₽ совпадает со строкой «<тип начисления>» от <дата> в отчёте по начислениям. Добавить акт всё равно?». По умолчанию выбран ответ «Нет»: акт не добавляется, остальные файлы импортируются как обычно, а в итоговом сообщении перечислены пропущенные акты.
- Если акт всё же добавлен, в «Контроль качества» отчёта записывается предупреждение «Двойной учёт акта». Оно сохраняется при пересчёте истории.
- Строки с артикулом, отрицательные суммы и строки другого месяца не считаются совпадением.
- Пример: июньская «Потеря по вине Ozon в логистике» на 359,10 ₽ и акт на 359,10 ₽ раньше давали 718,20 ₽ нераспределённых; теперь акт по умолчанию не добавляется и остаётся 359,10 ₽.
- Проверка вынесена в модуль `ozon_app/double_count.py` без зависимостей от интерфейса и покрыта тестами на синтетических данных.
- Расчётные формулы не изменены.
