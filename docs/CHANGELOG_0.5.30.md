# OZ Price Analyzer 0.5.30

- Налоговые ставки по периодам. В «Настройках» вместо поля «Налоговая ставка» — справочник «Действует с | Ставка, %» с кнопками «Добавить…», «Изменить…», «Удалить». Первая строка действует «с начала» и не удаляется, даты уникальны, ставка — от 0 до 100%. Справочник хранится в новой таблице SQLite `tax_rates` и входит в резервную копию.
- Ставка на дату — ставка строки с наибольшей датой «Действует с», не позже этой даты. Налог считается по дате каждой строки:
  - «Выручка», «Возврат выручки», «Программы партнёров» — по дате начисления;
  - выкупы Ozon — по «Дате» строки `BuyoutDetails`; в файле без дат строк (`RealizationReportCIS`) — по дате окончания периода отчёта о выкупах, а если этот период пересекает смену ставки, в «Контроль качества» записывается предупреждение «Налоговая ставка»;
  - положительные нераспределённые доходы — по дате начисления, PDF-акты — по дате акта;
  - «Баллы за скидки» в налоговую базу по-прежнему не входят.
- Налог каждого товара и налог с нераспределённых доходов сохраняются в базе (`product_results.tax`, `runs.unallocated_income_tax`) вместе со снимком справочника, по которому рассчитан отчёт (`run_tax_rates`), и интервалом дат налоговой базы.
- Миграция: при первом запуске справочник создаётся из прежней ставки настроек, а налог старых отчётов переносится как «база × сохранённая ставка отчёта». Результаты сохранённых отчётов не меняются — это проверяет тест миграции.
- Исправлено: объединённый обзор пересчитывал налог с нераспределённых доходов по средневзвешенной ставке. Теперь налог — сумма сохранённых налогов отчётов (июль 4% с компенсацией без артикула 1000 ₽ + август 6% дают 140 ₽ вместо 150 ₽).
- Сценарий цены использует ставку на дату окончания периода отчёта, для нескольких отчётов — самого позднего. Ставка подписана в карточке «Плановая чистая прибыль».
- Экспорт XLSX: налог товаров и налог с нераспределённых — значениями; в шапке `КонсОтчет` перечислены применённые ставки с периодами; ячейка P4 подписана «Ставка налога для сценария (на ДД.ММ.ГГГГ)».
- Изменение справочника ставок: программа находит сохранённые отчёты, которых касается изменение, пересчитывает их из сохранённых исходных файлов с исторической себестоимостью и показывает предпросмотр — отчёт, налог был, налог станет, изменение чистой прибыли товаров и чистой прибыли от деятельности. Только после подтверждения создаётся резервная копия, а справочник и отчёты сохраняются одной транзакцией; названия, даты расчёта и плановые цены сохраняются. При отмене не меняется ничего.
- «Пересчитать историю» пересчитывает каждый отчёт по его сохранённым ставкам и теперь заменяет отчёты одной транзакцией.
- Показатель «Итог с нераспределёнными после налога» переименован в «Чистая прибыль от деятельности» (карточка «Обзора», «Справка», XLSX); карточка «Чистая прибыль» — в «Чистая прибыль товаров». Формула не изменилась: чистая прибыль товаров (уже после налога товаров) + нераспределённые − налог с положительных нераспределённых доходов.
- «Справка» и README дополнены разделами о ставках по периодам, датах налога и ставке в сценарии цены.
- Новые тесты на синтетических данных: ставка на дату, смена ставки с 15-го числа, даты строк BuyoutDetails, миграция без изменения результатов, объединение месяцев с разными ставками, экспорт, предпросмотр и подтверждение пересчёта, резервная копия.
